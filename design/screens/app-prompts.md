# Prompts `/app/prompts`

Workspace prompt performance. Brand chips + filters. Links into report or brand prompt editor.

## Filters

All · Winning · Losing · No mention · Competitor wins · Recently changed

## Table columns

Prompt · Brand · Mix · Score · Status · Position · Competitors · Cited · Engines · Movement · Recheck (queues brand run, focuses that prompt on the run page; prompt text deep-links to brand `?recheck=`)

## Empty

No brands → Add a brand. No runs → Run a report to see prompt performance.
